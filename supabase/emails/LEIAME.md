# Modelos de e-mail do Já treinô? (Supabase → Authentication → Emails → Templates)

Cole o conteúdo de cada arquivo no campo **Message body** (modo código/HTML) do modelo correspondente e use o assunto indicado.

| Modelo no Supabase | Arquivo | Assunto (Subject) |
|---|---|---|
| Reset Password | redefinir-senha.html | Redefinir sua senha do Já treinô? |
| Invite user | convite.html | Você foi convidado para o Já treinô? |
| Confirm signup | confirmar-cadastro.html | Confirme seu e-mail no Já treinô? |
| Change Email Address | trocar-email.html | Confirme seu novo e-mail no Já treinô? |
| Magic Link | link-de-acesso.html | Seu link de acesso ao Já treinô? |

A logo vem de https://jatreino.app.br/marca/logotipo-email.png (PNG, porque Gmail e Outlook não mostram SVG).
